# ⏱️ ChronoTrack - Stopwatch App

A precise and smooth **Stopwatch Application** built using **Java and Android UI Framework**. ChronoTrack offers seamless timekeeping with state persistence during screen rotation and background transitions.

## ✨ Features

* ⏯️ Start, Pause, and Reset Functionality
* ⏱️ Real-time Display in `HH:MM:SS` Format
* 🔄 Screen Rotation State Handling via `SavedInstanceState`
* 📱 Dynamic Button State Controls (Enable/Disable Visual Feedback)
* ⏳ Background Timekeeping via Android Handler & Runnable
* 📱 Clean Centered UI Layout

## 🛠️ Built With

* Java (JDK 17)
* Android Handler & Looper
* Android XML Layouts
* Android Studio IDE

1. Clone or download this repository.
2. Open the project folder in **Android Studio**.
3. Build the Gradle project.
4. Launch the app using an **Android Emulator** or physical device.
